# 🤝 KeenKeeper

**Keep Friendship Alive**

KeenKeeper is a modern friendship management platform designed to help users maintain meaningful relationships through smart tracking, quick check-ins, and an interactive timeline. The platform makes it easier to stay connected with friends and strengthen relationships over time.

##  Live Demo

🔗 Live Site: https://kin-keeper-seven-self.vercel.app/

---

##  Key Features

### 👥 Smart Friends Dashboard

* Manage all your friends in one place
* View important friendship insights
* Organize and track relationships efficiently

### ⚡ Quick Check-In System

* Quickly record interactions with friends
* Stay updated with friendship activities
* Never lose touch with important connections

### 📅 Interactive Timeline

* Visual timeline of friendship memories
* Track important events and interactions
* View relationship history in an engaging way

###  Fully Responsive Design

* Optimized for mobile, tablet, and desktop devices
* Clean and user-friendly interface
* Smooth experience across all screen sizes

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/raselahmed2023/ken-keeper.git
cd ken-keeper
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

---

## 📦 Main Dependencies

```bash
npm install recharts react-icons react-toastify
```
